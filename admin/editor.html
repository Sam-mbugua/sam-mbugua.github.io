GitHub connection
Need a token? It lets this page save to your repository. Create one once:
  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → sam-mbugua.github.io.
  3. Permissions: Contents → Read and write. Optionally Pages → Read, so this page can tell you when the site is live.
  4. Generate, then paste the token above. Treat it like a password.
